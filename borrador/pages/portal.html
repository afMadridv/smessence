Gestión de catálogo

Registra una fragancia, decide en qué secciones aparece y exporta el archivo para publicarla.

Esta página no protege nada. El enlace del pie es discreto, pero cualquiera que conozca la dirección puede abrirla y todo el código viaja al navegador. Sirve para organizar el catálogo, no para guardar información reservada. Si algún día necesitas acceso restringido de verdad, hace falta un servidor con inicio de sesión.

    Cómo publicar lo que registraste

    1. Pulsa Exportar archivo: se descarga datos-portal.js.
    2. Cópialo junto a los demás archivos del generador, donde están datos.js, datos2.js y datos3.js.
    3. En generar.js añade la importación y súmalo al catálogo: 
      const { NUEVOS4 } = require('./datos-portal.js');
// …y dentro del arreglo CATALOGO:
...NUEVOS4.map(p => ({ ...p, imgKey: 'frascos/' + p.id + '.svg', vector: true }))
    4. Ejecuta node generar.js. Se crean la ficha, el packshot y las tarjetas en cada sección.

    La lista se guarda en este navegador. Si cambias de equipo o borras los datos del sitio, se pierde: exporta antes.
